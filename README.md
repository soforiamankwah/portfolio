# Simon Ofori-Amankwah - Portfolio

A one-page portfolio site. Everything is in `index.html` (photo embedded), so it works on its own.
`images/portrait.jpg` is a copy of the portrait in case you want to reuse it.

## Publish on GitHub Pages
1. Create a repository and upload all files in this folder.
2. Settings > Pages > Source: main branch, root folder > Save.
3. Your site goes live at https://your-username.github.io/repo-name/
